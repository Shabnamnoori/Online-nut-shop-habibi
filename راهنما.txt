راهنمای اجرای پروژه فروشگاه اینترنتی خشکبار «حبیبی»

فناوری‌های استفاده‌شده:
PHP 8
MySQL
Bootstrap 5
JavaScript
XAMPP

مراحل اجرای پروژه:

1. نرم‌افزار XAMPP را نصب و اجرا کنید.

2. Apache و MySQL را از داخل XAMPP روشن کنید.

3. پوشه HABIBI را در مسیر زیر قرار دهید:

C:\xampp\htdocs\HABIBI

4. وارد phpMyAdmin شوید:

http://localhost/phpmyadmin

5. یک دیتابیس با نام مورد استفاده پروژه ایجاد کنید.

6. فایل habibi.sql را از قسمت Import در phpMyAdmin وارد کنید.

7. فایل includes/config.php را بررسی کنید و در صورت نیاز اطلاعات اتصال دیتابیس را مطابق سیستم خود تنظیم کنید.

8. سپس پروژه را از آدرس زیر اجرا کنید:

http://localhost/HABIBI/

صفحه مدیریت:

http://localhost/HABIBI/admin/

نکته:
برای اجرای صحیح پروژه، Apache و MySQL باید در XAMPP فعال باشند.
